# Launch WMX R2 Manipulator
## Example: Dobot CR3A
```
wros ros2 launch wmx_r2_package wmx_r2_manipulator.launch.py \
    use_sim_time:=false \
    'config_file:=$(ros2 pkg prefix --share wmx_r2_package)/example/cr3a_manipulator_config.yaml' \
    'wmx_param_file:=$(ros2 pkg prefix --share wmx_r2_package)/example/cr3a_wmx_parameters.xml' \
    use_gripper:=true
```

## Example: Dobot CR3A with ROS2 Control
```
wros ros2 launch wmx_r2_control wmx_r2_control_manipulator.launch.py \
    use_sim_time:=false \
    'config_file:=$(ros2 pkg prefix --share wmx_r2_package)/example/cr3a_manipulator_config.yaml' \
    'wmx_param_file:=$(ros2 pkg prefix --share wmx_r2_package)/example/cr3a_wmx_parameters.xml' \
    'urdf_file:=$(ros2 pkg prefix --share wmx_r2_control)/urdf/cr3a.wmx.urdf.xacro' \
    'controllers_file:=$(ros2 pkg prefix --share wmx_r2_control)/config/cr3a_controllers.yaml' \
    use_gripper:=true
```

## Example: Dobot CR3A with ROS2 Control, cyclic-buffer position streaming
A stock `JointTrajectoryController` (`movensys_manipulator_arm_controller`) writes
`position` command interfaces that `WmxSystemHardware` streams to the servos through
the WMX3 cyclic buffer, so a planner can replace the running trajectory at any time
(`<arm_controller>/joint_trajectory` topic or `follow_joint_trajectory` action).
The standalone `joint_trajectory_controller` / `joint_position_controller` nodes are
not started in this mode. `hermite` samples the (position, velocity) cubic once per
engine cycle, so `cyclic_max_acc` trips on the real acceleration.
```
wros ros2 launch wmx_r2_control wmx_r2_control_manipulator.launch.py \
    use_sim_time:=false \
    'config_file:=$(ros2 pkg prefix --share wmx_r2_package)/example/cr3a_manipulator_config.yaml' \
    'wmx_param_file:=$(ros2 pkg prefix --share wmx_r2_package)/example/cr3a_wmx_parameters.xml' \
    'urdf_file:=$(ros2 pkg prefix --share wmx_r2_control)/urdf/cr3a.wmx.urdf.xacro' \
    'controllers_file:=$(ros2 pkg prefix --share wmx_r2_control)/config/cr3a_controllers_hermite.yaml' \
    stream_position:=true cyclic_subsample:=hermite cyclic_max_acc:=15
```
With `cyclic_subsample:=linear` use `config/cr3a_controllers_stream.yaml` (position only);
the engine then sees about (real acceleration) x (cycles per `write()`), so
`cyclic_max_acc` must be raised accordingly (about 100 for CR3A planner limits).
`activate_arm_controller:=false` loads the arm controller inactive: the buffer holds
position with nothing commanding it.
